# Learner feedback log

When the learner corrects the teaching, the agent adds one dated line here: what went wrong and what the learner wants instead. The `consolidate-rules` skill later folds entries into `TEACHING_RULES.md` and marks them `[merged]`. New rule sections are never pasted into the rules file directly; that is how rule files become long and get ignored.
