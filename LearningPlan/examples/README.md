# Teaching examples: what fails, what works

Three case studies of lessons on PPO (Module 07) that went wrong, and the versions that worked. They are composites written for this course: the situations are typical of what happened while the course was being developed, but all wording is paraphrased and nothing here is a transcript.

Read the one that matches what you are about to do. They teach the style faster than the rules do.

| File | Shows | Read before |
|---|---|---|
| [scattered_vs_structure_first.md](scattered_vs_structure_first.md) | A lesson that followed many formatting rules but left the learner lost, and the repair that worked | any lesson about an algorithm or data structure |
| [name_before_introduction.md](name_before_introduction.md) | Opening with a component of a method that was never introduced, and the whole-cycle version that fixed it | the first lesson of any new method |
| [results_as_text.md](results_as_text.md) | Results shown as a number table without the physical picture, and the visual redo | presenting any run or calculation result |

Positive full-format reference: `LearningProgress/08-microduck-task-lifecycle/lessons/L01-one-env-step/LESSON.md` (the format every lesson should follow).
